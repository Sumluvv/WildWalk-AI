# WildWalk AI 移动端 MVP 界面流程

## 页面 1：选路线

### 字段

- 路线名、难度、预计时长、天气摘要、海拔区间、推荐人数、简介

### 按钮

- `查看详情` `选择此路线` `继续`

### 关键交互规则

- 未选路线时 `继续` 按钮禁用，选中后才能进入房间。

## 页面 2：房间

### 字段

- 房间号、房主、成员列表、准备状态、目标路线

### 按钮

- `复制房间号` `准备/取消准备` `开始游戏` `退出房间`

### 关键交互规则

- 仅房主可开始，且至少 2 人已准备。

## 页面 3：回合操作

### 字段

- 回合编号、环境播报、个人状态条、行动选择、公聊输入、队友提交状态

### 按钮

- `提交行动` `发送聊天` `查看背包`

### 关键交互规则

- 每人每回合只能提交 1 次行动，提交后锁定等待结算。

## 页面 4：回合结算

### 字段

- 回合摘要、数值变化、事件结果、AI 叙事、下一回合状态快照

### 按钮

- `进入下一回合` `查看详细日志` `结束本局`

### 关键交互规则

- 所有玩家确认后再进入下一回合。

## 新手引导（3 步）

1. 选择 Demo 路线并进入房间。
2. 至少两人准备后，由房主开局。
3. 每人执行一次行动，查看结算并进入下一回合。

## 验收清单（6 条）

1. 未选路线不能进房间。  
2. 非房主不能开始游戏。  
3. 少于 2 人准备不可开始。  
4. 同回合不能重复提交行动。  
5. 结算页必须有“数值变化 + 叙事 + 事件”。  
6. 全员确认后才进入下一回合。
